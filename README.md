# Analytics and Reporting (SQL & Power BI)

## 📋 About the Project / Про проєкт
This repository presents the data analytics and business intelligence work completed for the project. The processing, data modeling, and interactive reporting layer were built using **SQL (PostgreSQL)**, **Power Query**, and **Power BI (DAX)**.

Цей репозиторій містить фінальні результати та детальну документацію аналітичної частини проєкту. Весь аналіз, обробка даних та побудова звітів виконані на основі єдиної моделі даних за допомогою **SQL (PostgreSQL)**, **Power Query** та **Power BI (DAX)**.
