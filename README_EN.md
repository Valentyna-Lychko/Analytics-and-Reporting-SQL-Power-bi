## 📋 Project Overview
This project focuses on comprehensive business analytics and interactive reporting to evaluate sales performance, analyze customer purchasing behavior, and monitor audience retention dynamics.

*This repository highlights my personal contribution and the analytical work I completed as part of this team project.*

## 🛠️ My Contribution to the Project
*   **Data Preparation:** cleaning and structuring historical data using Excel and Power Query.
*   **Database Preparation:** preparing data for a relational data model in PostgreSQL.
*   **SQL Analysis:** data processing and consolidation using SQL queries, including CTEs, window functions, and aggregations.
*   **Power BI Report Development:** creating interactive dashboards and calculated measures using DAX.
*   **Sales and Product Assortment Analysis:** analyzing sales, product assortment, and customer purchasing behavior.
*   **Customer Segmentation:** performing RFM analysis based on purchase recency, frequency, and monetary value.
*   **Cost Calculation:** automating the cost calculation for products.
*   **Customer Needs Research:** developing a questionnaire to collect information about customer needs.

## 🧰 Tools and Technologies
*   **Data Preparation:** Excel, Power Query
*   **Databases:** PostgreSQL (SQL)
*   **BI and Visualization:** Power BI, DAX
*   **Analytical Methods:** Sales and product assortment analysis, customer behavior analysis, RFM segmentation, churn analysis
